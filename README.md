# My own custom new tab page!

This is my own new tab page which has a cool backgroud, a nice search bar, it displays time and weather too.

## how to use it?

to start using it, type anything you want to search in the search bar and press enter!
you can also check weather in your city by entering your city name in the weather widget and clicking search.

you can try it [here](https://pahal-desai.github.io/New-Tab)
